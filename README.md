# monaibuhuihuahua 的个人博客

这是一个部署在 GitHub Pages 上的个人博客，当前是纯静态结构，但内容维护已经接了本地管理页。

## 当前结构

- `index.html`
  主页
- `thoughts/`
  生活感悟
- `algorithms/`
  算法题
- `photography/`
  生活摄影
- `assets/`
  头像和摄影图片资源
- `admin.html`
  本地内容管理页

## 三个板块的维护方式

### 生活感悟

- 不按时间建目录
- 只维护一个统一列表
- 输入项：
  - 标题
  - 时间
  - 内容
- 数据文件：
  - `thoughts/thoughts.json`

### 算法题

- 按题型整理
- 题型不存在时自动创建
- 输入项：
  - 题型
  - 题目网址
  - 题解
  - 感悟
- 自动生成：
  - 对应题型的 `json`
  - 对应题型页面
  - 算法首页归档

### 生活摄影

- 按年份 / 月份整理
- 年月不存在时自动创建
- 输入项：
  - 年份
  - 月份
  - 日期
  - 标题
  - 正文
  - 多张照片
- 自动生成：
  - 对应月份图片目录
  - 对应月份 `json`
  - 对应月份页面
  - 摄影首页归档

## 本地管理页

- `admin.html`

管理页包含三个标签：

- 摄影
- 生活感悟
- 算法题
