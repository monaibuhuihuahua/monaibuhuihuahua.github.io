GitHub Pages Feasibility Demo

先验证能不能部署，再决定要不要升级成更完整的博客系统。

这个原型采用纯静态 HTML + CSS，适合直接放到 GitHub 仓库中发布。 栏目设计按“可持续扩展”思路组织，后续可以继续加入读书、旅行、技术随笔等新板块。

部署方式

直接托管静态站点

最简单、风险最低，适合先把内容跑起来。

内容组织

按栏目逐步扩展

每个板块都能独立增长，不会把首页结构拖乱。

后续升级

需要时再接入框架

如果文章和图片越来越多，再迁移到 Astro、Next.js 或 Hugo 也很顺。

Blog Sections

你现在想要的三个核心板块

01 / 生活感悟

记录日常观察和成长思考

适合写短文、阶段总结、生活片段，也最能建立个人博客的“人味”。

  • 月度总结
  • 碎片思考
  • 读书或观影感受

02 / 算法题

沉淀刷题过程和解题方法

可以按题型、难度或平台分类，长期看会变成很有价值的个人知识库。

  • 数组与双指针
  • 二叉树与图
  • 动态规划总结

03 / 生活摄影

把照片和拍摄故事一起展示

GitHub Pages 也能很好承载摄影页面，只要做好图片压缩和相册分组。

  • 街头记录
  • 旅行影像
  • 器材与参数随记

Scalability

以后新增板块也不会推倒重来

新增栏目

只要复制一张栏目卡片，并增加对应页面或文章目录，就能扩展成读书、旅行、项目复盘等主题。

升级内容系统

当文章数量变多时，可以把当前静态结构迁移到支持 Markdown 的生成器，保留现有视觉设计。

摄影优化

可以加入图片懒加载、分辨率适配、Lightbox 相册浏览，提升阅读体验。
